SYSTEM NOTES

  • Data source: the app attempts a live fetch() against a public-domain, open-source North America airport dataset. If the request fails, times out, or is blocked by network policy, it seamlessly loads an embedded offline dataset covering major hubs and representative regional fields.
  • Significant-field filter: records are limited to United States and Canada, then narrowed to fields carrying a genuine 4-letter ICAO identifier (K.../P... for the US, C... for Canada) — this includes every towered, reliever, and municipal/GA airport with a real designator, while excluding private ranch strips, orchard strips, and ag airfields that only carry a local FAA-style location ID.
  • Runway data: published longest-runway figures are applied where known; any field without a confirmed value uses a conservative 5,000 ft baseline estimate.
  • Aircraft database: 21 entries — your own aircraft (speed, all-in rate, and fuel burn from YTD logged data) plus 20 specific researched types spanning single piston through ultra-long-range heavy jet. Search by manufacturer or model above the route builder.
  • Cost breakdown categories: follows standard business-aviation cost taxonomy. Fixed = crew salary/training, hangar, insurance (accrues whether you fly or not). Variable = crew travel, catering, airport/landing fees (scales with trips). MSP / Engine Reserve = hourly engine + APU overhaul funding, the kind of rate programs like JSSI or manufacturer MSPs actually charge. Maintenance Reserve = airframe scheduled/unscheduled upkeep. Defaults are seeded from real cost-model and POH data per aircraft, but every field is editable and persists per aircraft.
  • Data corrections: four of the largest jets (G450, G500, Global 5000, G650ER) in the researched dataset had an identical placeholder fuel-burn figure in the source cost model; each was corrected to a published manufacturer/Conklin & de Decker-sourced rate instead (flagged with a note when that aircraft is selected).
  • 1st-hour vs. cruise fuel burn: climb and early cruise burn measurably more fuel per hour than steady cruise. Each leg's first flight-hour uses the "1st Hour" rate; anything beyond that uses the "Subsequent" cruise rate. Defaults are estimated with a category-based climb multiplier (not certified POH climb-fuel data) — edit either field directly if you have better numbers.
  • Runway minimums: each jet aircraft carries its own reference minimum runway length used to trigger the runway advisory; turboprops and pistons are not runway-gated.
  • Wind correction: when enabled, each leg samples forecast wind speed/direction at the pressure level closest to the active aircraft's average cruise altitude (editable in the Aircraft Cost & Performance Profile) at the leg's midpoint, then applies the standard wind-triangle correction (headwind/tailwind component + crosswind-driven correction angle) to true airspeed. If the live forecast is unreachable, a labeled climatological average (prevailing westerly flow aloft) is used instead so the estimate degrades gracefully rather than failing outright. This is a single-sample-per-leg simplification, not a full route-integrated wind model — treat the result as directionally correct, not accurate to the knot.
  • Multi-stop & round trip: each leg — including mirrored return legs — is computed independently, then summed into trip totals. Taxi-out/taxi-in allowances apply per leg, not once for the whole itinerary. The runway advisory and shortest-runway stat check every stop the itinerary actually lands at.
  • Route map: renders the true great-circle path over a live dark basemap (CARTO). Requires an internet connection to load map tiles.
  • Publish Itinerary (PDF): renders a clean, printer-friendly summary of the currently computed itinerary — route, stats, leg-by-leg breakdown, fleet comparison, cost estimate, and alternates — and opens your browser's print dialog. Choose "Save as PDF" (or "Microsoft Print to PDF" on Windows, "Save to Files" on iOS) as the destination to export it. This uses the browser's native print engine rather than an external PDF library, so it works fully offline.
