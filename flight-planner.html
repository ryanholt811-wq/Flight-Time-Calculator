SYSTEM NOTES

  • Data source: the app attempts a live fetch() against a public-domain, open-source North America airport dataset. If the request fails, times out, or is blocked by network policy, it seamlessly loads an embedded offline dataset covering major hubs and representative regional fields.
  • Significant-field filter: records are limited to United States and Canada, then narrowed to fields carrying a genuine 4-letter ICAO identifier (K.../P... for the US, C... for Canada) — this includes every towered, reliever, and municipal/GA airport with a real designator, while excluding private ranch strips, orchard strips, and ag airfields that only carry a local FAA-style location ID.
  • Runway data: published longest-runway figures are applied where known; any field without a confirmed value uses a conservative 5,000 ft baseline estimate.
  • Fleet speeds: Single/Twin Piston, Midsize Jet, and Heavy Jet use a representative cruise TAS for aircraft typically flown in that class. Light Jet is different: its speed (389 kt), all-in rate ($4,472.66/hr), and fuel burn (234 gal/hr) are derived from the operator's own YTD logged flight data rather than an assumed constant.
  • Runway minimums: Light/Midsize/Heavy Jet categories each carry their own reference minimum runway length (4,000 / 5,000 / 6,000 ft) used to trigger the runway advisory.
  • Wind correction: when enabled, each leg samples forecast wind speed/direction at a representative cruise pressure-altitude for the active aircraft's category (e.g. 200 hPa / ~FL390 for Light Jet, 700 hPa / ~10,000 ft for Single Piston) at the leg's midpoint, then applies the standard wind-triangle correction (headwind/tailwind component + crosswind-driven correction angle) to true airspeed. If the live forecast is unreachable, a labeled climatological average (prevailing westerly flow aloft) is used instead so the estimate degrades gracefully rather than failing outright. This is a single-sample-per-leg simplification, not a full route-integrated wind model — treat the result as directionally correct (a genuine tailwind/headwind swap between reversed routes, matching real jet-stream behavior), not accurate to the knot.
  • Multi-stop & round trip: each leg — including mirrored return legs — is computed independently, then summed into trip totals. Taxi-out/taxi-in allowances in the cost calculator apply per leg, not once for the whole itinerary. The runway advisory and shortest-runway stat check every stop the itinerary actually lands at.
  • Route map: renders the true great-circle path over a live dark basemap (CARTO). Requires an internet connection to load map tiles.
  • Cost & fuel estimator: entirely user-supplied figures. The fuel-burn field is seeded with a rough per-category starting point only — replace it with your aircraft's actual POH/operating data for a trustworthy trip cost.
  • Publish Itinerary (PDF): renders a clean, printer-friendly summary of the currently computed itinerary — route, stats, leg-by-leg breakdown, fleet comparison, cost estimate, and alternates — and opens your browser's print dialog. Choose "Save as PDF" (or "Microsoft Print to PDF" on Windows, "Save to Files" on iOS) as the destination to export it. This uses the browser's native print engine rather than an external PDF library, so it works fully offline.
