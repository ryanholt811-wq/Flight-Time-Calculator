DATASET SCAN

Data: live pull attempted from a public-domain North America airport dataset; falls back to an embedded regional dataset if the feed is unreachable.

SYSTEM NOTES

  • Data source: the app attempts a live fetch() against a public-domain, open-source North America airport dataset. If the request fails, times out, or is blocked by network policy, it seamlessly loads an embedded offline dataset covering major hubs and representative regional fields.
  • Significant-field filter: records are limited to United States and Canada, then narrowed to fields carrying a genuine 4-letter ICAO identifier (K.../P... for the US, C... for Canada) — this includes every towered, reliever, and municipal/GA airport with a real designator, while excluding private ranch strips, orchard strips, and ag airfields that only carry a local FAA-style location ID. Roughly 2,900 US/CA fields pass this filter in live mode.
  • Runway data: published longest-runway figures are applied where known; any field without a confirmed value uses a conservative 5,000 ft baseline estimate.
  • Fleet speeds: Single/Twin Piston, Midsize Jet, and Heavy Jet use a representative cruise TAS for aircraft typically flown in that class — treat those as planning-order-of-magnitude figures. Light Jet is different: its speed (389 kt), all-in rate ($4,472.66/hr), and fuel burn (234 gal/hr) are derived from the operator's own YTD logged flight data (nm ÷ hours, total expense ÷ hours, fuel gallons ÷ hours) rather than an assumed constant.
  • Runway minimums: Light/Midsize/Heavy Jet categories each carry their own reference minimum runway length (4,000 / 5,000 / 6,000 ft) used to trigger the runway advisory. These are representative, not type-specific balanced-field-length data.
  • Route map: renders the true great-circle path over a live dark basemap (CARTO). Requires an internet connection to load map tiles; if unavailable, a text notice appears while the course indicator continues to work fully offline.
  • Cost & fuel estimator: entirely user-supplied figures. The fuel-burn field is seeded with a rough per-category starting point only — replace it with your aircraft's actual POH/operating data for a trustworthy trip cost. Engine run time = selected profile's flight ETE + your taxi-out and taxi-in allowances.
