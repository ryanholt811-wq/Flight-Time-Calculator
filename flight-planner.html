DATASET SCAN

⚠ PLANNING AID ONLY. Still-air, no-wind, no-terrain great-circle estimate. Not for actual flight navigation, dispatch, or FAR/AIM compliance.

Data: live pull attempted from a public-domain North America airport dataset; falls back to an embedded regional dataset if the feed is unreachable.

SYSTEM NOTES

  • Data source: the app attempts a live fetch() against a public-domain, open-source North America airport dataset. If the request fails, times out, or is blocked by network policy, it seamlessly loads an embedded offline dataset covering major hubs and representative regional fields.
  • Significant-field filter: records are limited to United States and Canada, then narrowed to fields carrying an active scheduled-service IATA code or a curated set of notable regional/GA fields — this removes closed strips, helipads, and private pads from the autocomplete pool.
  • Runway data: published longest-runway figures are applied where known; any field without a confirmed value uses a conservative 5,000 ft baseline estimate.
  • ETE model: distance ÷ true airspeed, still air, no wind or routing correction. Treat as a planning-order-of-magnitude figure only.
  • Alternates: computed live via a Haversine scan of the loaded dataset for the three nearest fields to the destination, excluding the origin and destination themselves.
